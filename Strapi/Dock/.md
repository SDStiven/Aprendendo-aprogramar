## 🏛️ Desenho da Arquitetura do Sistema

O objetivo é construir o ecossistema de backend de uma plataforma onde empresas listam os seus portfólios de código e os utilizadores gerem os seus projetos favoritos.

### 1. Modelos de Dados (Content-Types)
*   **Company (Collection Type):** Guarda os metadados das empresas parceiras.
*   **Project (Collection Type):** Armazena as informações dos projetos desenvolvidos.
*   **User (Core System Type):** Entidade nativa do Strapi adaptada para reter os favoritos.

### 2. Mapeamento de Relações
*   **Uma Empresa para Vários Projetos (1:N):** Uma `Company` possui uma lista de `Projects`. Um `Project` aponta para uma única `Company`.
*   **Muitos Utilizadores para Muitos Projetos (N:M):** Um `User` pode guardar múltiplos `Projects` nos seus favoritos. Um `Project` pode ser favoritado por múltiplos `Users`.
